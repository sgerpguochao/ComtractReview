## 1. 组件层级关系图

```
ReviewSummaryCard（审核结果总览）
├── FilterBar（筛选排序栏）
│   └── 批量操作按钮
└── RiskItemList（风险项列表）
    ├── GroupHeader（分组头部，每个等级一个）
    └── RiskItemCard（风险项卡片，可展开/收起）
        ├── ClauseLocator（原文定位组件）— 左栏
        ├── ReviewOpinionPanel（审查意见面板）— 右栏
        └── ReviewActionBar（审核操作栏）— 底部入口按钮
```

## 2. RiskItemList — 风险项列表组件

### 2.1 ASCII 线框图

```
┌─────────────────────────────────────────────────────────────┐
│ ▼ 高风险 (5)                                                │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ [高] 单方无限制解除权...          第5页  │ 92% │ [待处理] │  │
│  └───────────────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ [高] 违约金比例超出法定上限...      第8页  │ 88% │ [已确认] │  │
│  └───────────────────────────────────────────────────────┘  │
│                                                             │
│ ▶ 中风险 (8)                                                │
│                                                             │
│ ▶ 低风险 (12)                                               │
└─────────────────────────────────────────────────────────────┘
```

**展开态（某个分组展开）**：见上，分组内的卡片逐一展示，默认收起态。

**收起态（某个分组收起）**：仅显示分组 header，不展示卡片内容。

### 2.2 Props 接口

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `items` | `RiskItem[]` | 是 | 风险项数组，来自 API 3.6 `risk_items` |
| `onCardExpand` | `(riskId: string) => void` | 否 | 卡片展开时回调，触发 API 3.7 请求详情 |
| `onActionClick` | `(riskId: string, action: 'approve' \| 'modify' \| 'reject') => void` | 否 | 审核操作入口回调 |
| `defaultExpandedLevels` | `Set<'high' \| 'medium' \| 'low'>` | 否 | 默认展开的风险等级，默认 `{'high'}` |

### 2.3 子组件构成

- **GroupHeader**（×3，每个等级一个）：展示等级标签、统计数量、展开/收起箭头
- **RiskItemCard**（×N）：每个风险项一个卡片

### 2.4 数据来源

- `GET /api/v1/tasks/{task_id}/result` 返回的 `summary` 中的计数 + `risk_items` 数组
- 每个 RiskItem 的摘要字段：`risk_id`、`level`、`confidence`、`clause_position.page`、`human_review_status`

### 2.5 交互行为

- 点击分组 header 的展开/收起箭头切换该等级下所有卡片的显隐
- 高风险等级默认展开，中低风险默认收起
- 分组内卡片按 `confidence` 降序排列

### 4.3 Props 接口

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `item` | `RiskItem` | 是 | 风险项完整数据，来自 API 3.6 列表项或 3.7 详情 |
| `expanded` | `boolean` | 是 | 当前是否展开 |
| `onToggle` | `() => void` | 是 | 切换展开/收起 |
| `onAction` | `(action: 'approve' \| 'modify' \| 'reject') => void` | 否 | 审核操作回调，触发 API 3.8 |
| `loading` | `boolean` | 否 | 详情加载中，展开时展示骨架屏 |

### 4.4 子组件构成

- **ClauseLocator**：左栏原文定位区域（仅展开态展示）
- **ReviewOpinionPanel**：右栏审查意见区域（仅展开态展示）
- **ReviewActionBar**：底部审核操作按钮栏（仅展开态展示，具体审核 UI 由 teammate 3 设计）

### 4.5 数据来源

- 收起态所需字段（来自 API 3.6 列表接口即可）：
  - `risk_id`、`level`、`category`、`confidence`、`clause_position`（`section`、`clause`、`page`）、`description`、`suggestion`、`human_review_status`
- 展开态额外需要的字段（来自 API 3.7 详情接口）：
  - `clause_text`（原文完整内容）、`legal_basis`（法律依据，可能较长）、`description`（详细风险描述）、`suggestion`（完整修改建议）

### 4.6 状态映射

#### 风险等级样式

| level | 标签背景色 | 标签文字色 | 边框色 |
|-------|-----------|-----------|--------|
| `high` | `#FEF2F2` | `#DC2626` | `#DC2626` |
| `medium` | `#FFFBEB` | `#D97706` | `#D97706` |
| `low` | `#EFF6FF` | `#2563EB` | `#2563EB` |

#### 审核状态标签

| human_review_status | 标签文本 | 背景色 | 文字色 | 图标 |
|---------------------|---------|--------|--------|------|
| `pending` | "待处理" | `#F3F4F6` | `#6B7280` | — |
| `approved` | "已确认" | `#F0FDF4` | `#16A34A` | ✓ |
| `modified` | "已修改" | `#FFFBEB` | `#D97706` | ✎ |
| `rejected` | "已驳回" | `#FEF2F2` | `#DC2626` | ✕ |

#### 规则分类中文映射

| category | 中文标签 |
|----------|---------|
| `breach_of_contract` | 违约责任 |
| `intellectual_property` | 知识产权 |
| `confidentiality` | 保密条款 |
| `dispute_resolution` | 争议解决 |
| `contract_termination` | 合同解除 |
| `force_majeure` | 不可抗力 |
| `data_compliance` | 数据合规 |
| `payment_terms` | 付款条款 |
| `liability_limitation` | 责任限制 |
| `other` | 其他 |

#### 置信度条

- 0-50: 灰色 (`#9CA3AF`)，文字 "低"
- 51-80: 橙色 (`#D97706`)，文字 "中"
- 81-100: 绿色 (`#16A34A`)，文字 "高"

### 4.7 交互行为

- 点击卡片主体（非按钮区域）切换展开/收起
- 收起态仅展示单行摘要（description 前 30 字符 + 省略号）
- 展开态展示左右分栏原文对照
- 已处理状态（非 pending）的卡片整体透明度降至 60%，可折叠收起
- 展开时若详情数据未加载，展示骨架屏而非空白

```
┌─────────────────────────────────┐
│ 原文定位                         │
├─────────────────────────────────┤
│ 面包屑: 第八条 > 第2款 · 第5页  │
├─────────────────────────────────┤
│                                 │
│  ...前序条款文本...              │
│  ┌───────────────────────────┐  │

│  │ 无需承担任何违约责任。      │  │
│  │ (黄色底色 #FEF9C3 高亮)    │  │
│  └───────────────────────────┘  │
│  ...后续条款文本...              │
│                                 │
├─────────────────────────────────┤
│ 位置: 第5页 | 偏移: 1024-1156   │

```

**关键风险词红色下划线态**（当条款中存在明确风险关键词时）：

```
│  ┌───────────────────────────┐  │
│  │ 甲方有权单方面解除本合同，  │  │
│  │ 无需承担任何违约责任。      │  │

│  │     (红色下划线标记)        │  │

```

### 5.2 Props 接口

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `clauseText` | `string` | 是 | 条款完整原文，来自 API 3.7 `clause_text` |
| `position` | `TextPosition` | 是 | 原文定位信息，来自 API 3.7 `clause_position` |
| `highlightOffsets` | `{ start: number, end: number }[]` | 否 | 需要额外标记的关键风险词偏移区间 |
| `contextLines` | `number` | 否 | 高亮区域前后展示的上下文行数，默认 3 |

### 5.3 TextPosition 子字段映射

| 字段 | 展示格式 | 必填 | 来源 |
|------|---------|------|------|
| `section` | "第八条" | 否 | API 3.7 `clause_position.section` |
| `clause` | "第2款" | 否 | API 3.7 `clause_position.clause` |
| `page` | "第5页" | 否 | API 3.7 `clause_position.page` |
| `offset_start` | 用于定位高亮起始 | 是 | API 3.7 `clause_position.offset_start` |
| `offset_end` | 用于定位高亮结束 | 是 | API 3.7 `clause_position.offset_end` |

### 5.4 子组件构成

- **PositionBreadcrumb**：面包屑导航，展示 section > clause · page
- **TextHighlightBlock**：带高亮的文本展示区域
  - 风险条款全文中 `offset_start` ~ `offset_end` 区间应用黄色底色 (`#FEF9C3`)
  - 若传入 `highlightOffsets`，在这些区间额外应用红色下划线
- **PositionFooter**：底部位置信息，展示页码和偏移量

### 5.5 数据来源

- API 3.7 `GET /api/v1/tasks/{task_id}/risks/{risk_id}` 返回的 `clause_text` + `clause_position`

### 5.6 交互行为

- 高亮区域自动滚动到可视范围（展开时聚焦到黄色底色区域）
- 文本区域支持选中复制
- 若 `clause_position` 中 `section`/`clause`/`page` 缺失，对应面包屑部分不展示

### 6.2 Props 接口

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `description` | `string` | 是 | 风险描述，来自 API 3.7 `description` |
| `legalBasis` | `string` | 是 | 法律依据，来自 API 3.7 `legal_basis` |
| `suggestion` | `string` | 是 | 修改建议，来自 API 3.7 `suggestion` |
| `confidence` | `number` | 是 | AI 置信度 0-100，来自 API 3.7 `confidence` |
| `onCopy` | `(text: string) => void` | 否 | 复制回调，默认写入剪贴板 |

### 6.3 子组件构成

- **RiskDescriptionBlock**：风险描述段落，完整展示不截断
- **LegalBasisBlock**：法律依据区块
  - 默认最多展示 2 行，超出以省略号截断
  - 点击"展开"展示全部文本
  - 文本可能较长，来源于后端 LLM 生成的法律条文引用
- **SuggestionBlock**：修改建议区块
  - 带"复制"按钮，点击后写入 `suggestion` 到系统剪贴板
  - 复制成功后展示 2 秒"已复制"提示后恢复
- **ConfidenceBar**：置信度指示条

### 6.4 数据来源

- API 3.7 `GET /api/v1/tasks/{task_id}/risks/{risk_id}` 返回的 `description`、`legal_basis`、`suggestion`、`confidence`

### 6.5 交互行为

- 法律依据区域支持展开/收起（文本较长时）
- 修改建议的复制按钮：点击后调用 `navigator.clipboard.writeText`
- 复制成功时按钮文字切换为"已复制"，2 秒后恢复为"复制"
- 置信度低于 50 的项在指示条旁展示"低置信度，建议人工复核"提示

### 7.2 Props 接口

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `summary` | `ReviewResult` | 是 | 审查结果汇总，来自 API 3.6 `summary` |
| `remainingHighRisks` | `number` | 是 | 剩余待处理高风险项数量，来自 API 3.8/3.9 响应 `remaining_pending` |
| `onGenerateReport` | `() => void` | 否 | 生成报告回调，触发 API 3.10 |
| `reportGenerating` | `boolean` | 否 | 报告生成中状态 |

### 7.3 子组件构成

- **RiskScoreDisplay**：总体风险评分展示（分数 + 等级标签）
- **RiskCountCards**（×3）：高/中/低风险数量统计卡片
- **ReportActionSection**：生成报告按钮区域 + 剩余高风险提示

### 7.4 数据来源

- API 3.6 `GET /api/v1/tasks/{task_id}/result` 返回的 `summary` 对象：
  - `total_risks`、`high_count`、`medium_count`、`low_count`、`summary`
- API 3.8/3.9 响应中的 `remaining_pending` 字段用于更新剩余待处理数

### 7.5 评分等级映射

基于后端返回的统计计算风险评分（前端本地计算，后端不直接返回评分）：

计算公式：`score = (high_count * 10 + medium_count * 5 + low_count * 2)`，上限 100

| 分数范围 | 等级标签 | 颜色 |
|---------|---------|------|
| 0-30 | "低风险" | `#16A34A` |
| 31-60 | "中等风险" | `#D97706` |
| 61-100 | "高风险" | `#DC2626` |

### 7.6 生成报告按钮状态逻辑

| 条件 | 按钮状态 | 说明 |
|------|---------|------|
| `remainingHighRisks > 0` | disabled | 仍有高风险未处理 |
| `remainingHighRisks === 0` | enabled | 可生成报告 |
| `reportGenerating === true` | loading | 生成中，展示旋转指示器 |
| 后端返回 `HIGH_RISKS_PENDING` | disabled + 错误提示 | 接口层面二次校验 |

## 8. FilterBar — 筛选排序栏组件

### 8.1 ASCII 线框图

```
┌─────────────────────────────────────────────────────────────────┐
│ 风险等级: [●全部] [  高  ] [  中  ] [  低  ]                    │
│ 审核状态: [●全部] [ 待处理 ] [ 已处理 ]                          │
│ 排序: [置信度 降序 ▼]    共 25 项    [批量确认] [批量驳回]        │
└─────────────────────────────────────────────────────────────────┘

筛选激活态：
┌─────────────────────────────────────────────────────────────────┐
│ 风险等级: [全部] [● 高  ] [  中  ] [  低  ]                    │
│ 审核状态: [●全部] [ 待处理 ] [ 已处理 ]                          │
│ 排序: [置信度 降序 ▼]    共 5 项 (已筛选)  [批量确认] [批量驳回]  │
│                                    (仅筛选项非空时激活)            │
└─────────────────────────────────────────────────────────────────┘
```

### 8.2 Props 接口

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `totalItems` | `number` | 是 | 当前筛选后的项目总数 |
| `selectedItems` | `Set<string>` | 是 | 当前选中的风险项 ID 集合 |
| `onFilterChange` | `(filters: FilterState) => void` | 否 | 筛选条件变化回调 |
| `onSortChange` | `(sort: SortOption) => void` | 否 | 排序变化回调 |
| `onBatchAction` | `(action: 'approve' \| 'reject') => void` | 否 | 批量操作回调，触发 API 3.9 |
| `onSelectionChange` | `(ids: Set<string>) => void` | 否 | 批量选择变化回调 |

### 8.3 FilterState 类型

```
interface FilterState {
  level: 'all' | 'high' | 'medium' | 'low'
  reviewStatus: 'all' | 'pending' | 'handled'  // 'handled' = approved | modified | rejected
}
```

### 8.4 SortOption 类型

```
type SortOption =
  | 'confidence_desc'   // 置信度从高到低
  | 'confidence_asc'    // 置信度从低到高
  | 'level_desc'        // 风险等级从高到低
  | 'level_asc'         // 风险等级从低到高
  | 'status_asc'        // 待处理优先
```

### 8.5 子组件构成

- **LevelFilterGroup**：风险等级筛选按钮组（全部/高/中/低）
- **StatusFilterGroup**：审核状态筛选按钮组（全部/待处理/已处理）
- **SortSelector**：排序下拉选择器
- **ItemCountBadge**：筛选结果计数展示
- **BatchActionButtons**：批量确认 + 批量驳回按钮
  - 仅当 `selectedItems.size > 0` 时激活

### 8.6 数据来源

- 筛选和排序在前端本地执行，不请求后端
- 数据来源于 API 3.6 一次性获取的 `risk_items` 数组
- 筛选条件对应 API 3.6 查询参数 `level` 和 `review_status`（若后续改为服务端筛选可直接对接）

### 8.7 交互行为

- 筛选为前端本地操作，即时响应
- 多个筛选条件之间为 AND 关系
- 排序默认值为 `level_desc`（高风险优先）
- 批量操作按钮仅在有选中项时可用
- 批量确认后弹出二次确认对话框（不可逆操作提示）

## 9. ReviewActionBar — 审核操作入口组件

### 9.1 ASCII 线框图

```
┌────────────────────────────────────────────────────────────┐
│ [同意]          [修改]          [驳回]                      │
│ (确认AI判定)    (编辑内容/等级)  (驳回非风险项)               │
└────────────────────────────────────────────────────────────┘

已处理态（不可重复操作）：
┌────────────────────────────────────────────────────────────┐
│ ✓ 已确认 — 操作人: user-001 | 2026-04-10 07:00             │
│   审核意见: 同意AI的风险判定                                │
└────────────────────────────────────────────────────────────┘
```

### 9.2 Props 接口

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `riskId` | `string` | 是 | 风险项 ID |
| `currentStatus` | `HumanReviewStatus` | 是 | 当前审核状态，来自 API 3.6/3.7 `human_review_status` |
| `decision` | `HumanDecision \| null` | 否 | 已有的人工决策，来自 API 3.7 `human_decision` |
| `onAction` | `(action: 'approve' \| 'modify' \| 'reject') => void` | 是 | 操作触发回调 |
| `disabled` | `boolean` | 否 | 是否禁用（非 pending 状态时禁用） |

### 9.3 行为说明

- 本组件仅负责审核操作的**入口展示和触发**，不实现 approve/edit/reject 的具体表单 UI
- `onAction` 回调由父组件接管，父组件负责：
  - 对于 `approve`：直接调用 API 3.8 `action: approve`
  - 对于 `modify`：打开编辑面板（由 teammate 3 设计）
  - 对于 `reject`：打开驳回原因输入（由 teammate 3 设计）
- 已处理状态（非 `pending`）下按钮组 disabled，展示已完成的决策摘要
- 决策摘要展示：动作标签 + 操作人（`human_decision.operator`）+ 时间（`human_decision.created_at`）+ 审核意见（`human_decision.comment`）

### 9.4 数据来源

- API 3.6 列表接口：`human_review_status` 字段用于判断按钮可用状态
- API 3.7 详情接口：`human_decision` 对象用于展示决策摘要
  - `action`、`comment`、`operator`、`created_at`
