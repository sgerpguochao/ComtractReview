## 1. 核心业务问题

### 1.1 问题定义

传统合同审查存在**三个不可调和的矛盾**：

| 矛盾 | 表现 | 后果 |
|------|------|------|
| 效率 vs 质量 | 人工审查要质量就必须慢，要快就容易遗漏 | 企业要么承担时间成本，要么承担风险成本 |
| 标准化 vs 个性化 | 不同审查人员标准不一，经验依赖强 | 同一份合同不同人审出不同结果 |
| 自动化 vs 可靠性 | LLM 能做到自动化但不可靠（误报 5%-35%），纯人工可靠但效率低 | 纯自动化在法务场景不可行 |

### 1.2 Agent 智能文档审核系统要解决的核心问题

基于调研结论，系统要解决的核心业务问题是：

**在保障审查质量（不遗漏关键风险）的前提下，通过 AI Agent 自动化初审 + 人工复核（HITL）的混合模式，将合同审查效率从"小时级"提升到"分钟级"，同时降低人为遗漏率（从 5%-15% 降至 <2%）。**

拆解为三个子问题：

| 子问题 | 来源 | 说明 |
|--------|------|------|
| **如何自动识别合同中的风险条款** | 业务调研 | LLM + 规则引擎的混合方案，覆盖条款提取、风险识别、合规检查 |
| **如何让人高效确认/修正 AI 的判断** | 竞品分析 | HITL 机制：interrupt 暂停 → approve/edit/reject 决策 → 恢复执行 |
| **如何清晰呈现审核结果让决策有据可依** | 竞品分析 | 风险项列表 + 原文定位 + 解释性数据（法律依据、置信度） |

## 3. MVP 业务场景

基于调研结论中"必须环节"和"可简化环节"的结论，MVP 场景裁剪如下：

### 场景 1：上传合同并自动审查

**触发条件**：法务人员收到待审合同（Word/PDF）

**用户操作流程**：
1. 登录系统，上传单份合同文件
2. 选择审查维度（风险审查 / 合规检查）
3. 系统自动解析合同并执行 Agent 初审
4. 生成风险项列表（按风险等级排序）

**系统行为**：
- 文档解析 → 条款边界识别 → 条款提取 → 风险识别 → 生成风险列表
- 每个风险项包含：原文位置、风险说明、风险等级（高/中/低）、置信度

**对应核心问题**：如何自动识别合同中的风险条款

### 场景 2：人工审核高风险项

**触发条件**：Agent 初审完成，存在高风险项需要人工确认

**用户操作流程**：
1. 进入审查详情页，查看风险项列表
2. 逐条处理高风险项：
   - 查看原文高亮定位 + AI 判断依据 + 法律依据
   - 做出决策：**确认**（认同 AI 判断）/ **修正**（调整风险等级或审查意见）/ **驳回**（认为误报）
3. 中低风险项可批量确认或跳过

**系统行为**：
- 对高风险项触发 HITL interrupt，等待人工决策
- 记录每次人工操作（确认/修正/驳回）及原因
- 根据决策结果更新风险项状态

**对应核心问题**：如何让人高效确认/修正 AI 的判断

### 场景 3：查看并导出审查报告

**触发条件**：所有高风险项审核完成

**用户操作流程**：
1. 查看审查报告首页（总体风险评分 + 风险统计）
2. 逐条查看风险详情和修改建议
3. 导出 PDF 审查报告

**系统行为**：
- 生成结构化审查报告：执行摘要 + 风险详情清单 + 修改建议汇总
- 支持 PDF 导出

**对应核心问题**：如何清晰呈现审核结果让决策有据可依

## 4. 从功能清单到业务建模的映射

| 功能模块 | 支撑的业务场景 | 核心数据实体 | 后续设计影响 |
|----------|---------------|-------------|-------------|
| 文档上传与解析 | 场景 1 | Contract（合同）、Document（文档） | 数据模型需支持文档版本管理 |
| 条款提取 | 场景 1 | Clause（条款）、ClauseType（条款类型） | API 需返回结构化条款数据 |
| 风险识别 | 场景 1 | RiskItem（风险项）、RiskLevel（风险等级） | 前端需支持风险等级视觉区分 |
| HITL 人工审核 | 场景 2 | ReviewTask（审核任务）、ReviewDecision（审核决策） | 架构需支持 interrupt/restore 机制 |
| 审查报告 | 场景 3 | ReviewReport（审查报告）、ReportSummary（报告摘要） | 前端需两级信息架构（总览+详情） |

## 5. MVP 范围边界

### 明确包含
- [x] 单文件上传（Word/PDF）
- [x] 文档解析与条款提取
- [x] 风险条款自动识别（高/中/低三级）
- [x] 高风险项人工审核（确认/修正/驳回）
- [x] 审查报告查看与 PDF 导出
- [x] 审核操作日志记录（用于 AI 优化反馈）

### 明确排除（MVP 不做）
- [ ] 批量上传（竞品分析结论：二期功能）
- [ ] API 集成上传（竞品分析结论：Ironclad 特色，非 MVP 必须）
- [ ] 模板深度比对（结论：初期只做简单差异对比，后续扩展）
- [ ] 多法域适配（结论：技术难度高，MVP 先覆盖单一法域）
- [ ] 团队协作功能（评论/@提及/任务分配）
- [ ] 扫描件的 OCR 处理（结论：可简化环节）
