# 合同审核结果呈现分析

## 1. 审核结果呈现维度

### 1.1 风险项列表

#### 展示方式
| 展示形式 | 特点 | 代表产品 |
|----------|------|----------|
| 卡片列表 | 每个风险项一张卡片，展示摘要信息 | LegalSifter |
| 表格视图 | 结构化表格，适合批量对比 | Kira Systems |
| 树形结构 | 按条款层级组织，适合复杂合同 | Luminance |
| 时间线视图 | 按合同段落顺序排列 | Ironclad |

#### 风险等级视觉标识
- **高风险（红色）**：可能导致重大经济损失或法律纠纷的条款
  - 单方无限制解除权、无限责任、管辖地严重不利
- **中风险（橙色/黄色）**：需要关注但可协商的条款
  - 违约金偏高、付款条件不对等、保密范围过宽
- **低风险（绿色/蓝色）**：建议优化但不影响核心利益的条款
  - 表述不清晰、术语不标准、缺少建议性条款

#### 排序逻辑
- 默认按**风险等级降序**排列（高风险优先）
- 支持按**合同段落顺序**排序（方便逐条审核）
- 支持按**条款类型**分组排序（价格类、责任类、期限类）

### 1.2 原文定位

#### 位置标注方式
| 定位方式 | 精度 | 用户体验 | 技术实现难度 |
|----------|------|----------|-------------|
| 高亮原文 | 精确到词 | 最佳 | 高（需要字符级映射） |
| 行号锚点 | 精确到行 | 良好 | 中 |
| 页码+段落号 | 精确到段落 | 一般 | 低 |
| 条款编号引用 | 精确到条款 | 依赖合同编号规范 | 低 |

#### 原文与审查意见的关联方式
- **左右分栏对照**：左侧原文高亮，右侧审查意见（Kira Systems 的 Reviewer 模式）
  - 优点：直观对照
  - 缺点：屏幕空间利用率低
- **弹窗/抽屉模式**：点击风险项弹出原文对照（Ironclad 的 Quick View）
  - 优点：节省空间，适合移动端
  - 缺点：需要频繁打开/关闭
- **内联注释**：在原文中直接嵌入审查批注（类 Word 审阅模式）
  - 优点：所见即所得
  - 缺点：原文和批注混杂，视觉干扰

#### 跨条款引用处理
- 当风险涉及多个条款的联动关系时（如违约责任与赔偿上限）
- 需要同时高亮多个位置的原文，并建立关联链接
- Luminance 使用"连接点"（link points）标记关联条款

### 1.3 解释性数据展示

#### AI 判断依据呈现
| 数据类型 | 说明 | 展示方式 |
|----------|------|----------|
| 法律依据 | 引用具体法规条文（如《民法典》第 XXX 条） | 超链接到法规全文 |
| 相似案例 | 历史上类似合同的处理结果 | 卡片列表 |
| 行业标准 | 行业通用的条款范围参考 | 对比图表 |
| 风险推理链 | AI 从条款到风险结论的推理步骤 | 折叠面板/流程图 |

#### 风险评分可视化
- **总体风险评分**：0-100 分或 1-5 星，让用户快速把握整体风险
- **维度评分**：按法律风险、商业风险、合规风险分别评分（雷达图）
- **风险趋势**：修改后的风险评分变化（对比原版本）

#### 置信度展示
AI 的不确定性需要透明传达：
- **高置信度（>90%）**：AI 判断可靠，可直接采纳
- **中置信度（70%-90%）**：建议人工复核
- **低置信度（<70%）**：高度建议人工判断，AI 仅供参考

可视化方式：置信度条（类似进度条）、星级、文字标签（"确定"/"较确定"/"不确定"）

## 2. 各竞品结果呈现对比

| 呈现维度 | Kira Systems | Luminance | Ironclad | LegalSifter |
|----------|-------------|-----------|----------|-------------|
| 风险项列表 | 表格+筛选 | 仪表板+图表 | 卡片列表 | 卡片+标签 |
| 原文定位 | 左右分栏+高亮 | 智能高亮+连接点 | 弹窗对照 | 内联批注 |
| 解释性数据 | 有限（条款标签） | 丰富（相似案例） | 中等（规则说明） | 丰富（专家注解） |
| 风险评分 | 无总体评分 | 有置信度指示 | 有规则匹配度 | 有风险等级 |
| 导出格式 | Excel+PDF | PDF+仪表板 | JSON+PDF | PDF+Word |
| 交互方式 | 批量标注 | 智能过滤 | 工作流审批 | 评论协作 |

## 3. 交互模式分析

### 3.1 审核人员操作
| 操作 | 说明 | 交互方式 |
|------|------|----------|
| 展开/收起详情 | 查看风险项的完整分析 | 点击展开面板 |
| 标记已处理 | 标记已审核的风险项 | 勾选/滑动标记 |
| 添加批注 | 记录审核意见或修改建议 | 文本输入框 |
| 调整风险等级 | 修正 AI 的风险评级 | 下拉选择或拖拽 |
| 标记误报 | 告知 AI 判断错误 | 一键标记+可选原因 |

### 3.2 筛选和过滤
- **按风险等级**：只看高风险项 / 只看中风险项 / 只看低风险项
- **按条款类型**：只看价格类 / 只看责任类 / 只看保密类
- **按处理状态**：未处理 / 已处理 / 已驳回（误报）
- **按 AI 置信度**：低置信度优先（需要人工判断的条款）

### 3.3 分享和协作
- **内部评论**：法务团队成员之间就某个风险项进行讨论
- **@提及**：将特定条款指派给相关负责人（如将税务条款指派给财务人员）
- **任务分配**：将审核任务拆分给不同人员并行处理
- **版本对比**：修改后与原审查结果对比，查看风险变化

## 4. 结果呈现设计建议

### 4.1 信息架构
```
首页（总览）
├── 合同基本信息（名称、版本、上传时间）
├── 总体风险评分（仪表盘）
├── 风险项统计（高/中/低数量）
├── 快速入口（未处理的风险项）
│
├── 详细审查页
│   ├── 风险项列表（可筛选/排序）
│   ├── 单个风险项详情
│   │   ├── 原文高亮定位
│   │   ├── AI 风险说明
│   │   ├── 置信度指示
│   │   ├── 法律依据
│   │   ├── 修改建议
│   │   └── 操作区（确认/修正/驳回/批注）
│   │
│   └── 原文视图（可选切换）
│
└── 审查报告
    ├── 执行摘要
    ├── 风险详情清单
    └── 修改建议汇总
```

### 4.2 视觉层级
1. **第一层**：风险等级（颜色编码，一眼识别优先级）
2. **第二层**：条款类型（标签分组，快速理解问题领域）
3. **第三层**：具体建议（详细说明，指导如何修改）

### 4.3 交互原则
- **最少点击**：审核人员应在 2 次点击内完成一个风险项的处理
- **渐进式披露**：默认显示摘要，按需展开详细信息
- **快捷操作**：支持批量处理同类风险项（如"全部确认为低风险"）
- **可追溯性**：每次人工修正都记录操作日志，为 AI 优化提供数据
