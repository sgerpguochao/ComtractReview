# 前端设计规格 — ContractReview v1.0

> 本文档严格基于 `03_problem_modeling/problem_core.md` 和 `04_interaction_design/interaction_core_final.md` 收口而成，不做自主发散。
> 本文档作为前端实现计划的输入规范，定义了页面清单、结构层次、跳转关系和核心交互。

---

## 1. 页面清单

| 编号 | 页面名称 | 路由 | 说明 | MVP 优先级 |
|------|----------|------|------|-----------|
| P1 | 首页 / 工作台 | `/` | 用户入口，展示审查历史，上传合同入口 | P0 |
| P2 | 审查详情页 | `/review/:id` | 合同审查全流程主页面（上传→解析→审核→报告） | P0 |
| P3 | 报告预览页 | `/review/:id/report` | 审查报告在线预览 | P0 |

## 3. 页面跳转关系

```
┌─────────┐
│  P1 首页  │
└────┬────┘
     │
     │ ① 上传合同（选择文件 + 校验通过）
     ↓
┌──────────────┐
│  P2 审查详情页 │ ← 状态：上传成功，自动跳转
└──────┬───────┘
       │
       │ ② 解析 + AI 审查自动进行（同页面状态流转）
       │    解析中 → AI 审查中 → 待人工审核
       │
       │ ③ 高风险项全部处理完成后，"生成报告"按钮激活
       ↓
┌──────────────┐
│  P3 报告预览页 │ ← 点击"在线预览"跳转
└──────┬───────┘
       │
       │ ④ 点击"下载"→ 浏览器下载 PDF
       │ ⑤ 点击"返回审查详情"→ 回到 P2
       ↓
┌──────────────┐
│  P2 审查详情页 │
└──────┬───────┘
       │
       │ ⑥ 点击"返回首页"→ 回到 P1
       ↓
┌─────────┐
│  P1 首页  │
└─────────┘
```

| 编号 | 触发条件 | 源页面 | 目标页面 | 跳转方式 |
|------|---------|--------|---------|---------|
| ① | 文件上传成功 | P1 | P2 | 路由跳转 + 传递 reviewId |
| ② | 自动状态流转 | P2 | P2（同页） | 状态更新，不跳转 |
| ③ | 点击"在线预览" | P2 | P3 | 路由跳转 |
| ④ | 点击"下载" | P2/P3 | 浏览器下载 | 触发文件下载，不跳转 |
| ⑤ | 点击"返回审查详情" | P3 | P2 | 路由返回 |
| ⑥ | 点击"返回首页" | P2 | P1 | 路由跳转 |

## 4. 核心交互规范

### 4.1 上传交互
| 交互 | 规范 |
|------|------|
| 拖拽上传 | 拖入文件时上传区域边框高亮（蓝色虚线→实线），拖出时恢复 |
| 文件校验 | 客户端即时校验（格式、大小、重复），失败即时提示 |
| 上传进度 | 确定进度条（有百分比），显示已上传/总大小 |
| 上传取消 | 上传中可点击 × 取消，取消后恢复初始状态 |

### 4.2 审核进度交互
| 交互 | 规范 |
|------|------|
| 阶段轮播 | 解析阶段每 3 秒切换提示文案（结构识别→条款提取→文本清洗） |
| 后台运行 | 点击后最小化进度面板，用户可离开页面，完成后通知 |
| 断点续审 | 失败重试时已完成的阶段显示 ✓ 跳过 |

### 4.3 风险项交互
| 交互 | 规范 |
|------|------|
| 风险等级颜色 | 高=红色(#DC2626)、中=橙色(#D97706)、低=蓝色(#2563EB) |
| 原文高亮 | 风险条款黄色底色(#FEF9C3)，关键风险词红色下划线 |
| 展开/收起 | 默认收起，点击展开显示左右分栏详情 |
| 已处理弱化 | 已处理项透明度 60%，默认折叠 |
| 批量操作 | 选中后底部浮动工具栏显示"已选择 X 项" |

### 4.4 审批操作交互
| 操作 | 确认方式 | 反馈 |
|------|---------|------|
| 同意 | 低置信度(<70%)弹确认对话框，高置信度内联确认 | Toast "已确认" |
| 编辑 | 右侧滑出抽屉面板(480px)，预填 AI 原意见 | Toast "已修正" + 显示变更标记 |
| 驳回 | 内联展开驳回面板，选择预设原因 + 可选补充 | Toast "已驳回（误报）" |

### 4.5 状态同步
| 场景 | 规范 |
|------|------|
| 后台审核完成 | 系统通知 + 站内消息 + 页面返回时自动刷新 |
| 多端一致性 | WebSocket/SSE 推送状态变更，多标签页同步 |
| 文档锁定 | 审核中显示锁定标记，禁止替换文档 |

## 5. 状态枚举

```
ContractStatus:
  - UPLOADED        (已上传)
  - PARSING         (解析中)
  - PARSE_FAILED    (解析失败)
  - AI_REVIEWING    (AI 审查中)
  - AI_REVIEW_FAILED (AI 审查失败)
  - PENDING_REVIEW  (待人工审核)
  - MANUAL_REVIEWING (人工审核中)
  - COMPLETED       (审查完成，报告可导出)
  - CANCELLED       (已取消)
```
