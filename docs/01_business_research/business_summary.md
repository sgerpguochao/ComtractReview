# 业务调研总结

> 本阶段调研由 Agent Team 协作完成：
> - **researcher**：负责正向调研合同/法务文档审查 Agent 场景应用
> - **reviewer**：负责反方审查，识别技术难点与风险

---

## 调研结论概述

AI Agent 在合同/法务文档审查领域已具备**明确的商业价值和技术可行性**，但受限于 LLM 的不确定性，**纯自动化方案不可行**，必须采用"Agent 初审 + 人工复核"的混合模式。

### 核心发现

1. **市场验证**：Kira Systems、Luminance、Ironclad 等产品已在法律科技市场验证了 AI 合同审查的商业可行性，市场规模持续增长
2. **技术路线收敛**：行业正从传统 NLP + 规则引擎转向大模型 + RAG + HITL 混合方案
3. **HITL 是刚需**：法律审查结论具有法律效力，人工复核是不可替代的风险兜底机制
4. **误报是核心挑战**：LLM 幻觉和过度保守倾向导致误报率偏高（标准合同 ~5%，跨境合同 ~35%），直接影响用户信任

## 场景分析（researcher 输出摘要）

| 维度 | 结论 |
|------|------|
| 目标用户 | 企业法务、律所律师、合规部门、采购/销售团队 |
| 核心价值 | 效率提升（小时→分钟）、遗漏率降低（5-15%→<2%）、成本优化 |
| 审查对象 | 条款提取、风险识别、合规检查、一致性校验、完整性检查 |
| 审核粒度 | 整体级 + 条款级 + 词句级三层审查 |
| HITL 必要性 | 法律效力 + LLM 不确定性 + 责任归属明确化 |
| 推荐架构 | Agent 初审 + 人工复核 + Agent 生成报告（人机协同模式） |

## 技术挑战（reviewer 输出摘要）

| 挑战类别 | 风险等级 | 说明 |
|----------|----------|------|
| 误报问题 | 高 | LLM 幻觉 + 过度保守 → 误报率 5%-35% |
| 漏报风险 | 极高 | 遗漏关键条款 → 企业签署不利合同 |
| 可解释性 | 高 | 审核人员需要 AI 判断依据的推理链 |
| 数据隐私 | 高 | 合同含商业机密，第三方 API 存在泄露风险 |
| 模型稳定性 | 中 | 不同版本审查结果不一致 |
| 多法域适配 | 高 | 不同法域对同一术语定义不同 |

## LangChain HITL 的关键作用

在合同审查场景中，LangChain 的 Human-in-the-Loop 能力扮演着**不可替代的桥梁角色**：

1. **风险控制**：interrupt 机制确保高风险决策必须经过人工确认
2. **灵活决策**：approve/edit/reject 三种类型覆盖不同审核场景
3. **异步审核**：状态持久化支持审核人员异步处理，不阻塞 Agent 流程
4. **反馈学习**：审核人员的修正意见可被结构化记录，为 Agent 持续优化提供数据基础
