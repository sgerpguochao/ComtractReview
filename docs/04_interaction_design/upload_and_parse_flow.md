# 上传与解析交互链路设计

## 1. 上传入口设计

### 1.1 入口位置
- **首页主操作区**：页面中央"上传合同"按钮（主按钮，蓝色填充，带上传图标）
- **导航栏快捷入口**：顶部导航栏右侧"+"按钮，下拉菜单包含"上传合同审查"
- **空状态引导**：当用户无历史审查记录时，显示空状态页 + 上传引导

### 1.2 上传对话框布局
点击上传按钮后弹出模态对话框（600px 宽）：

```
┌─────────────────────────────────────────────┐
│  上传合同                              [×]  │
├─────────────────────────────────────────────┤
│                                             │
│     ┌─────────────────────────────────┐    │
│     │                                 │    │
│     │        📄 拖拽文件到此处        │    │
│     │           或                    │    │
│     │      [ 选择文件 ]              │    │
│     │                                 │    │
│     └─────────────────────────────────┘    │
│                                             │
│     支持格式：Word (.docx)、PDF（文本型）   │
│     文件大小限制：≤ 50MB                    │
│     暂不支持：扫描件、图片、TXT 等格式      │
│                                             │
└─────────────────────────────────────────────┘
```

### 1.3 文件选择交互
- 点击"选择文件"按钮 → 弹出系统文件选择器
- 文件选择器过滤条件：默认只显示 `.docx` 和 `.pdf` 文件
- 拖拽上传：支持从文件管理器拖入文件到上传区域
- 拖入时高亮上传区域边框（蓝色虚线变实线）

## 2. 上传校验流程

### 2.1 校验规则（按执行顺序）

| 校验项 | 规则 | 失败提示文案 |
|--------|------|-------------|
| 文件是否为空 | 文件大小 > 0 | "文件为空，请选择有效文件" |
| 文件格式 | 扩展名 .docx / .pdf | "不支持的文件格式。目前支持 Word (.docx) 和 PDF（文本型）文件" |
| MIME Type | application/vnd.openxmlformats... / application/pdf | "文件格式与扩展名不匹配，请检查文件是否损坏" |
| 文件大小 | ≤ 50MB | "文件大小超过 50MB 限制，请压缩后重新上传" |
| 重复检测 | 与最近 7 天内上传的同名同大小文件比对 | "该文件在 3 天前已上传并已审查，是否 [查看历史审查] 或 [重新上传]？" |

### 2.2 不支持格式的提示
当用户上传不支持的格式（如扫描件 .pdf 图片型、.txt、.jpg 等）时：

```
┌─────────────────────────────────────────────┐
│  ⚠️ 不支持的文件格式                         │
│                                             │
│  当前文件：合同扫描件.pdf（图片型 PDF）      │
│  支持格式：Word (.docx)、PDF（文本型）       │
│                                             │
│  💡 提示：如果您的合同是扫描件，建议先使用   │
│  OCR 工具转换为可编辑文本后再上传。          │
│  此功能将在后续版本中支持。                  │
│                                             │
│                        [ 知道了 ]          │
└─────────────────────────────────────────────┘
```

## 3. 上传进度反馈

### 3.1 上传中状态
文件校验通过后进入上传阶段，对话框内容切换为进度展示：

```
┌─────────────────────────────────────────────┐
│  正在上传合同...                      [×]  │
├─────────────────────────────────────────────┤
│                                             │
│     📄 采购合同_2026Q2.docx                 │
│     ████████████████░░░░  65%              │
│     已上传 3.2MB / 4.9MB                   │
│     正在上传，请稍候...                    │
│                                             │
└─────────────────────────────────────────────┘
```

- 进度条使用确定进度（有百分比），显示已上传大小和总大小
- 上传速度估算（可选显示）
- 支持上传中取消（右上角 × 按钮，点击后中断上传并恢复初始状态）

### 3.2 上传失败处理
```
┌─────────────────────────────────────────────┐
│  ❌ 上传失败                                 │
├─────────────────────────────────────────────┤
│                                             │
│  文件：采购合同_2026Q2.docx                 │
│  原因：网络连接中断，上传已中断              │
│                                             │
│  [ 重新上传 ]    [ 取消 ]                   │
│                                             │
└─────────────────────────────────────────────┘
```

常见失败原因及文案：
| 原因 | 提示文案 |
|------|---------|
| 网络中断 | "网络连接中断，上传已中断" |
| 服务器超时 | "服务器响应超时，请稍后重试" |
| 存储空间不足 | "服务器存储空间不足，请联系管理员" |

## 4. 解析任务创建与状态反馈

### 4.1 自动创建解析任务
上传成功后，自动关闭上传对话框，页面跳转至"审查详情页"，同时：
- 页面顶部显示 Toast 通知："文件上传成功，正在解析文档..."
- 解析任务在后台自动创建，用户无需手动触发

### 4.2 解析中状态
审查详情页首次加载时显示解析中状态：

```
┌─────────────────────────────────────────────┐
│  采购合同_2026Q2.docx                       │
│  状态：🔄 正在解析文档...                   │
├─────────────────────────────────────────────┤
│                                             │
│           ⏳ 文档解析中                      │
│                                             │
│     正在识别文档结构和条款边界...           │
│     ██████████████░░░░░░░  60%             │
│                                             │
│     预计剩余时间：约 30 秒                  │
│                                             │
└─────────────────────────────────────────────┘
```

解析阶段提示文案轮播（每 3 秒切换）：
1. "正在识别文档结构..."
2. "正在提取条款边界..."
3. "正在清洗文本内容..."

### 4.3 解析完成自动跳转
解析完成后，页面自动切换至 Agent 审核状态（进入下一环节）：
- Toast 通知："文档解析完成，开始 AI 审查..."
- 状态栏从"解析中"更新为"AI 审查中"

## 5. 解析失败处理

### 5.1 解析失败页面
```
┌─────────────────────────────────────────────┐
│  ❌ 文档解析失败                             │
├─────────────────────────────────────────────┤
│                                             │
│  文件：采购合同_2026Q2.docx                 │
│  上传时间：2026-04-09 14:30                │
│                                             │
│  失败原因：文档内容为空或无法识别           │
│  （该文件可能是图片型 PDF 或已损坏）        │
│                                             │
│  ─────────────────────────────────────      │
│  您可以：                                   │
│                                             │
│  [ 🔄 重新上传 ]  选择其他文件重新上传      │
│  [ 📋 查看帮助 ]  查看支持的文件格式说明    │
│                                             │
└─────────────────────────────────────────────┘
```

### 5.2 失败原因分类

| 原因分类 | 触发条件 | 提示文案 |
|----------|---------|---------|
| 格式不支持 | 实际为图片型 PDF | "该文件可能是图片型 PDF，暂不支持扫描件解析" |
| 文件损坏 | 文件结构异常无法读取 | "文件已损坏或格式异常，请检查后重新上传" |
| 内容无法识别 | 文本内容为空或非合同文本 | "文档内容为空或无法识别为合同文本" |
| 系统错误 | 解析服务异常 | "系统异常，请稍后重试或联系客服" |

## 6. 完整状态流转图

```
用户点击上传
    ↓
┌──────────────┐
│  上传对话框   │ ← 拖入/选择文件
└──────┬───────┘
       ↓
┌──────────────┐     失败 → 提示错误，返回上传对话框
│  格式校验    │
└──────┬───────┘
       ↓ 通过
┌──────────────┐     失败 → 提示原因，支持重试
│  文件上传    │
└──────┬───────┘
       ↓ 成功
┌──────────────┐     失败 → 提示原因，支持重新上传
│  文档解析    │
└──────┬───────┘
       ↓ 成功
┌──────────────┐
│ AI 审查中    │ → 进入 review_state_handling 环节
└──────────────┘
```
