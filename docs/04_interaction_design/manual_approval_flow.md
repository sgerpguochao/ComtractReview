### 1.2 风险等级视觉规范
| 等级 | 颜色 | 图标 | 背景色 | 边框色 |
|------|------|------|--------|--------|
| 高风险 | #DC2626 红色 | ⚠️ | #FEF2F2 | #FECACA |
| 中风险 | #D97706 橙色 | ⚡ | #FFFBEB | #FDE68A |
| 低风险 | #2563EB 蓝色 | ℹ️ | #EFF6FF | #BFDBFE |

### 1.3 处理状态标识
| 状态 | 标签 | 视觉 |
|------|------|------|
| 待处理 | `[待处理]` | 灰色标签，白色背景 |
| 已确认 | `[已确认]` | 绿色标签 |
| 已修正 | `[已修正]` | 蓝色标签 |
| 已驳回 | `[已驳回]` | 灰色标签 + 删除线 |

### 1.4 已处理项视觉弱化
- 透明度降至 60%
- 已确认/已修正/已驳回的风险项默认折叠
- 提供"显示已处理项"切换开关

### 2.2 原文高亮规则
- 风险条款原文以黄色高亮底色标记（`#FEF9C3`）
- 关键风险词以红色下划线标记（如"无需承担违约责任"）
- 点击高亮区域可滚动到合同原文对应位置

## 3. 审批操作区设计

### 3.1 同意（Approve）
**触发方式**：点击"✅ 同意"按钮

**交互行为**：
- 弹出轻量确认（非模态，内联提示）："确认认同此风险判断？"
- 确认后风险项状态变更为 `[已确认]`
- 条目自动折叠并视觉弱化
- Toast 通知："已确认风险 1"

**需要二次确认的情况**：
- 该风险项 AI 置信度为"低"（<70%）时，弹出确认对话框：
  ```
  此风险项 AI 置信度较低（65%），请确认是否认同？
  [ 确认同意 ]  [ 重新考虑 ]
  ```

### 3.2 编辑（Edit）
**触发方式**：点击"✏️ 编辑"按钮

**编辑面板**（右侧滑出抽屉面板，宽度 480px）：
```
┌─────────────────────────────────────────┐
│  ✏️ 修正审查意见                    [×] │
├─────────────────────────────────────────┤
│                                         │
│  风险等级  [ 高风险 ▼ ]                 │
│            ○ 高  ○ 中  ○ 低            │
│                                         │
│  审查意见                               │
│  ┌─────────────────────────────────┐   │
│  │ 该条款赋予甲方单方无限制...     │   │
│  │ （预填 AI 原意见，可编辑）      │   │
│  │                                 │   │
│  │                                 │   │
│  └─────────────────────────────────┘   │
│                                         │
│  建议修改                               │
│  ┌─────────────────────────────────┐   │
│  │ 建议增加对等解除权或限制...     │   │
│  │ （预填 AI 原建议，可编辑）      │   │
│  │                                 │   │
│  └─────────────────────────────────┘   │
│                                         │
│  修正原因（选填）                       │
│  ┌─────────────────────────────────┐   │
│  │ 补充说明修正理由...             │   │
│  └─────────────────────────────────┘   │
│                                         │
│  [ 保存修正 ]    [ 取消 ]               │
└─────────────────────────────────────────┘
```

**保存后行为**：
- 状态变更为 `[已修正]`
- 显示修正痕迹标记："已修正 [ 查看变更 ]"
- 点击查看修正前后对比
- Toast 通知："已修正风险 1"

### 3.3 驳回（Reject）
**触发方式**：点击"❌ 驳回"按钮

**驳回面板**（内联展开，无需弹出对话框）：
```
┌────────────────────────────────────────────────────────────────────┐
│  ❌ 驳回此风险项                                                   │
│                                                                    │
│  请选择驳回原因：                                                  │
│  ○ 非风险条款 — 该条款属于正常商业约定，不构成风险                │
│  ○ 风险等级过高 — 存在一定风险但不应评为高风险                    │
│  ○ 条款表述正常 — 该条款表述清晰，无不利影响                      │
│  ○ 其他原因（请在下方说明）                                        │
│                                                                    │
│  补充说明（选填）：                                                │
│  ┌──────────────────────────────────────────────────────────────┐ │
│  │                                                              │ │
│  └──────────────────────────────────────────────────────────────┘ │
│                                                                    │
│  [ 确认驳回 ]    [ 取消 ]                                          │
└────────────────────────────────────────────────────────────────────┘
```

**驳回后行为**：
- 状态变更为 `[已驳回]`，标签显示"误报"
- 条目折叠并灰色展示
- Toast 通知："已驳回风险 1（标记为误报）"
- 该驳回记录用于 AI 误报率统计和模型优化

## 4. 批量操作设计

### 4.1 批量选择
- 列表顶部提供"☐ 全选"复选框
- 每个风险项前有独立复选框
- 选中后底部浮动工具栏显示："已选择 X 项"

### 4.2 批量确认
```
底部浮动工具栏：
┌─────────────────────────────────────────────┐
│  已选择 3 项    [ 批量确认 ]  [ 批量驳回 ]  │
└─────────────────────────────────────────────┘
```
- 点击"批量确认"弹出确认对话框：
  ```
  确认将选中的 3 个风险项全部标记为"已确认"？
  [ 确认 ]  [ 取消 ]
  ```

### 4.3 批量驳回
- 批量驳回适用于 AI 置信度较低的高风险项
- 点击"批量驳回"弹出确认对话框：
  ```
  确认将选中的 2 个风险项全部标记为"已驳回（误报）"？
  [ 确认驳回 ]  [ 取消 ]
  ```

## 5. 审核完成与报告生成

### 5.1 全部处理完成
当所有高风险项处理完成后：

```
┌────────────────────────────────────────────────────────────────────┐
│  ✅ 所有高风险条款已处理完毕                         [ 生成报告 ]  │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│  处理结果统计：                                                    │
│  🔴 高风险 5 项：✅ 已确认 2 项  ✏️ 已修正 2 项  ❌ 已驳回 1 项   │
│                                                                    │
│  "生成报告"按钮从灰色变为可点击（蓝色填充）                        │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
```

### 5.2 报告生成
- 点击"生成报告"后显示进度：
  ```
  正在生成审查报告... ████████░░  80%
  ```
- 生成完成后自动下载 PDF 文件
- 同时支持在线预览报告

## 6. 操作日志与审计追踪

### 6.1 日志记录内容
每次操作记录以下信息：
| 字段 | 说明 |
|------|------|
| 操作人 | 用户名/ID |
| 操作时间 | 精确到秒 |
| 操作类型 | 同意 / 编辑 / 驳回 |
| 风险项 | 风险编号 + 条款位置 |
| 变更内容 | 编辑时的变更前对比 |
| 操作备注 | 用户填写的补充说明 |

### 6.2 日志查看入口
- 在审查详情页顶部提供"📋 操作日志"按钮
- 点击后展开日志面板（时间线形式）：
```
📋 操作日志

2026-04-09 14:35:22  张三  同意  风险1（单方解除权）
2026-04-09 14:36:05  张三  修正  风险2（无限责任）  高风险→中风险
2026-04-09 14:37:18  张三  驳回  风险3（管辖地）  原因：非风险条款
```

## 7. 完整交互流程图

```
进入人工审核页
    ↓
┌──────────────┐
│ 查看风险列表  │ ← 筛选/排序/批量选择
└──────┬───────┘
       ↓
┌──────────────┐
│ 展开风险项详情 │ ← 查看原文 + AI依据 + 建议
└──────┬───────┘
       ↓
┌──────────────┐
│ 选择审批操作  │
└──┬───┬───┬───┘
   ↓   ↓   ↓
 同意  编辑  驳回
   ↓   ↓   ↓
 状态  填写  选择
 变更  修正  原因
   ↓   ↓   ↓
┌──────────────┐
│ 状态更新完成  │
└──────┬───────┘
       ↓
  是否还有高风险项？
  ├── 是 → 继续处理下一项
  └── 否 → 生成审查报告
```
